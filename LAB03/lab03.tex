Next, we need to assign weights to each neighboring polygon. In our
case, each neighboring polygon will be assigned equal weight
\texttt{(style="W")}. This is accomplished by assigning the fraction:
\texttt{1\ /\ (\ \#\ of\ neighbors)} to each neighboring county then
summing the weighted values. While this is the most intuitive way to
summaries the neighbors' values it has one drawback in that polygons
along the edges of the study area will base their lagged values on fewer
polygons thus potentially over- or under-estimating the true nature of
the spatial autocorrelation in the data. For this example, we'll stick
with the \texttt{style="W"} option for simplicity's sake but note that
other more robust options are available, notably \texttt{style="B"}.

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{lw }\OtherTok{\textless{}{-}} \FunctionTok{nb2listw}\NormalTok{(nb, }\AttributeTok{style=}\StringTok{"W"}\NormalTok{, }\AttributeTok{zero.policy=}\ConstantTok{TRUE}\NormalTok{)}
\end{Highlighting}
\end{Shaded}

The \texttt{zero.policy=TRUE} option allows for lists of non-neighbors.
This should be used with caution since the user may not be aware of
missing neighbors in their dataset. However, a zero.policy of
\texttt{FALSE} would return an error if you have a dataset where a
polygon does not have a neighbor.

\subsection{Questions:}\label{questions}

\begin{Shaded}
\begin{Highlighting}[]
\CommentTok{\#1. Describe in your own words how Moran’s I is calculated? }

\CommentTok{\#Answer: Moran’s I measures the degree of spatial autocorrelation, meaning whether similar values are located near each other. It compares the value at each location with the values of its neighboring locations. If nearby areas have similar values (high with high or low with low), Moran’s I is positive. If nearby areas are very different, it becomes negative.}

\CommentTok{\#2. Describe in your own words: what is a spatially{-}lagged variable? }

\CommentTok{\#Answer: A spatially{-}lagged variable is the average (or weighted average) of values from neighboring areas for each location. It represents the local spatial context and shows what the surrounding areas look like compared to a given location.}

\CommentTok{\#3. How does your analysis in this lab (as simple as it is) differ by how you have formalized W (e.g., space, neighbors) in two diﬀerent methods? How might it affect analysis? }

\CommentTok{\#Answer: The difference is how neighbors are defined. The Queen method defines neighbors based on shared borders, meaning any counties that touch are considered equal neighbors. In contrast, the IDW method defines neighbors based on distance, where closer counties have a stronger influence and farther counties have less influence. The effect is that Queen can sometimes be unrealistic, especially when large counties touch but are physically far apart. IDW is often more realistic because it considers actual distance, which better reflects how real{-}world processes (such as population patterns or ecological processes) change gradually over space.}

\CommentTok{\#4. What does it mean if an observation falls in the “H{-}L” quadrant? Why might it be useful to detect such occurances? }

\CommentTok{\#Answer: "H{-}L" means a county has a High value but is surrounded by neighbors with Low values. This is useful for spotting spatial outliers or unique local anomalies (like a highly{-}educated college town surrounded by rural farmland) that don\textquotesingle{}t match the broader regional trend.}
\end{Highlighting}
\end{Shaded}
